AI-SERVICE 4.2.0 LARGE-SCALE - INSTALACIÓN SOBRE PROYECTO EXISTENTE

1. Haz respaldo de la carpeta ai-service original.
2. Abre el ZIP, copia sus archivos y carpetas SOBRE la raíz de tu proyecto ai-service. Sobrescribe los archivos de código existentes.
3. Conserva tu archivo .env, carpeta data/cases y volumen Docker spm-ollama-models.
4. Abre PowerShell en la raíz y ejecuta:
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\REDEPLOY_CPU_LOCAL.ps1

Alternativa manual:
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\migrate_env_cpu.ps1
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-local-model.ps1
  docker compose -f .\docker-compose.local.yml --env-file .\.env build --no-cache profile-intelligence-api
  docker compose -f .\docker-compose.local.yml --env-file .\.env up -d --force-recreate
  curl.exe http://localhost:3651/health
  docker logs --tail 100 profile-intelligence-api

NO ejecutes docker compose down -v: eso destruiría los pesos del modelo.
Importante: copiar archivos encima NO borra automáticamente ficheros antiguos del destino. No deben estar en el build si .dockerignore está actualizado.
La descarga de qwen3:1.7b requiere conectividad con registry.ollama.ai; en redes corporativas restringidas importa el modelo offline.

Pruebas verificadas en entorno de preparación (sin inferencia real de Ollama): 51 passed, 2 skipped por ausencia local de la dependencia ijson. No se ejecutó inferencia real Ollama ni Docker Desktop.

ESCALA GRANDE: no enviar millones de vínculos al endpoint chat.
1. Generar o disponer de un JSON que contenga perfil y/o grafo.
2. Subirlo UNA VEZ: POST /api/v1/cases?caseId=EXPEDIENTE con cuerpo JSON crudo.
3. Consultar: GET /api/v1/cases/EXPEDIENTE/links?nodeId=...&limit=30
4. Chat normal: {"profile":{"profileId":"..."},"caseId":"EXPEDIENTE","question":"..."}
5. Para grafo seleccionado: agregar "selectedNode":{"id":"NODO"}.
Para probar: python GENERAR_CASO_MASIVO.py --links 100000 --output caso_masivo_ficticio.json
Luego: powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\PROBAR_CASO_MASIVO.ps1
No sobrescribir .env ni eliminar datos/cases ni volumen spm-ollama-models.
Para millones de enlaces necesita espacio de disco adicional para JSON e índices; use AI_CASE_HOST_DIR fuera de OneDrive.
